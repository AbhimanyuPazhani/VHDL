# VHDL Projects Repository

## Overview
This repository contains a collection of VHDL projects developed during my internship at NSIC Technical Service Centre, Chennai (Ekkatuthangal branch) from May 2024 to June 2024.

The work focuses on fundamental digital design concepts implemented using VHDL, along with simulation, synthesis, and verification using ModelSim and Altera tools.

All projects in this repository are fully compiled, synthesized, and validated with testbenches. Supporting outputs and waveform/images are also included in PNG format.

## Project List

### 1. 3-Bit Counter
- Implements a basic synchronous counter using VHDL  
- Demonstrates sequential logic design and state transitions  

### 2. AND Logic Gate
- Basic combinational logic implementation  
- Demonstrates fundamental gate-level modeling in VHDL  

### 3. D Latch
- Level-sensitive storage element  
- Demonstrates timing behavior and latch operation  

### 4. Digitally Controlled Oscillator (DCO)
- Generates oscillation based on digital control inputs  
- Demonstrates timing control and frequency variation concepts  

### 5. Dynamic Multiplexer
- Multiplexer with dynamically controlled selection lines  
- Demonstrates flexible signal routing  

### 6. Multiplexer
- Standard multiplexer implementation  
- Demonstrates combinational logic and data selection  

### 7. Multiplexer with Counter
- Integration of multiplexer and counter logic  
- Demonstrates interaction between combinational and sequential circuits
